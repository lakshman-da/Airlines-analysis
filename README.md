# ✈️ Airlines Analysis

This project investigates various operational, financial, and customer-centric factors influencing airline performance and profitability. Using a data-driven approach with exploratory analysis, SQL queries, and statistical methods, the goal is to uncover actionable insights for airlines, analysts, and stakeholders.

---

## 🎯 Objectives

- Explore and identify **key factors** that impact airline performance (e.g., ticket pricing, occupancy rate, flight duration, class mix).  
- Use **visualizations and correlations** to surface patterns in the data.  
- Leverage **SQL queries** for efficient data manipulation and extraction.  
- Perform **statistical tests** to validate hypotheses and derive meaningful inferences.  
- Structure the project in a **modular, documented way**, making it future-proof and easily extendable.

---

## 📋 Dataset Overview

We use a dataset containing airline operational and financial data that includes features such as:

This structured dataset is ideal for both exploratory and predictive analysis of airline operations and profitability.

## 📐 Statistical Methods

- **Independent T-Test** → Compare revenue/occupancy between fare classes or aircraft types  
- **One-Way ANOVA** → Test differences in metrics across multiple aircraft codes or fare classes  
- **Correlation / Heatmap Analysis** → Explore relationships between revenue, occupancy, fares, capacity etc.
